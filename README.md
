# CubeTrack csTimer Bridge

This repo now includes a polished Chrome extension that can pull solve data from csTimer and import it into the CubeTrack dashboard automatically.

What is included:
- `manifest.json` — Chrome extension manifest
- `background.js` — runtime bridge logic between the popup and csTimer/CubeTrack tabs
- `content-cstimer.js` — reads solve data from the csTimer page
- `content-cubetrack.js` — accepts imported solves and merges them into the page state
- `index.html`, `app.js`, `style.css` — the CubeTrack popup/dashboard UI

How to use:
1. Open Chrome and go to `chrome://extensions`.
2. Turn on Developer mode.
3. Click Load unpacked and select this repository folder.
4. Open a csTimer tab and leave it active.
5. Click the CubeTrack Bridge extension icon.
6. Press `Sync from csTimer`.
7. The extension will fetch solves from csTimer and send them to the CubeTrack page.

Optional configuration:
- You can set your CubeTrack URL in the popup if you are running the app on a local server or a custom host.
- By default it points to the GitHub Pages site for this repository.

Notes:
- The extension is designed to work with the current CubeTrack front-end pattern already present in this repo.
- It is intentionally defensive: it tries multiple common csTimer local-storage structures and filters out duplicates.
